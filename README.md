🍕 Pizza Sales Analysis & Dashboard | SQL + Power BI


📝 Short Description / Purpose
This project analyzes pizza sales data to understand sales performance, customer ordering patterns, product performance, revenue contribution, and business trends using SQL and Power BI.
The goal is to transform raw transactional data into an interactive dashboard that helps management make data-driven decisions about products, pricing, promotions, and sales strategy.

🛠️ Tech Stack
SQL / MySQL – Data querying, analysis, joins, aggregations and advanced SQL
Power BI – Interactive dashboard and data visualization
DAX – Measures, KPIs and calculated metrics
Microsoft Excel – Initial data inspection and preparation
GitHub – Project documentation and portfolio
SQL Concepts Used
SELECT, WHERE, GROUP BY, ORDER BY
Aggregate functions: SUM(), AVG(), COUNT()
JOIN
Subqueries
HAVING
CASE
Window Functions
RANK()
Cumulative Revenue
Revenue Contribution %
Time-based analysis

🎯 Goal of the Dashboard
The main goal of the dashboard is to provide a single interactive view of pizza sales performance.

The dashboard helps stakeholders:

Monitor overall sales performance.
Identify high-performing and low-performing pizzas.
Understand customer ordering behavior.
Analyze revenue by category and product.
Identify peak ordering periods.
Support promotional and inventory decisions.
Improve product and pricing strategies.

💡 Business Impact and Insights
The analysis can help the pizza business make better operational and strategic decisions.

🍕 Product Strategy
High-revenue and high-demand pizzas can be prioritized for:
Promotions
Inventory
Featured menu placement
Upselling

Low-performing pizzas can be reviewed for possible menu optimization or repositioning.

📦 Inventory Management
Understanding pizza size and category demand can help the business maintain appropriate inventory levels and reduce unnecessary stock.

👨‍🍳 Staff Planning
Hourly order analysis can help identify peak periods so the business can allocate more employees during high-demand hours.

📢 Marketing & Promotions
Revenue and order trends can be used to create targeted promotions during slower periods and maximize sales during high-demand periods.

💰 Revenue Optimization
Average Order Value and category-level revenue analysis can help identify opportunities to increase revenue through:
Combo offers
Cross-selling
Premium pizza recommendations
Size upgrades

📊 Data-Driven Decision Making
Instead of relying only on assumptions, management can use the dashboard to make decisions based on actual sales and customer ordering data.

🚀 Project Outcome
This project demonstrates how SQL can be used to extract meaningful business insights from transactional data and Power BI can transform those insights into an interactive business dashboard.
The final dashboard provides stakeholders with a clear view of sales, revenue, products, categories, customer ordering patterns, and business performance.
